# Études urbaines

Статический сайт авторских фотоотпечатков Игоря Печорского. Четыре работы, два размера листа, предварительные цены, оформление заказа в личном Telegram автора. Рамы показаны только как примеры оформления.

## Запуск

Для вспомогательных скриптов рекомендуется Node.js 22.12+. Сборка для публикации не нужна.

```sh
node scripts/serve.cjs
```

Открыть http://127.0.0.1:4173/. Сервер обслуживает только публичные файлы сайта, не содержимое Git или документацию.

## Где менять содержимое

- `catalog.js` — единственный источник данных четырёх работ, цены 5 900/9 900 ₽, размеры листа, расчёт полей и текст заказа.
- `index.html` — общие тексты о продукте, доставке, авторе и контактах.
- `script.js` — карточки, hash-навигация, выбор размера и оформления, копирование текста, увеличение фотографии.
- `style.css` — внешний вид и адаптивная вёрстка.
- `assets/web/` — подготовленные JPEG для загрузки на сайте. Оригиналы в `assets/` сохраняются.
- `SPEC.md` — согласованное ТЗ и операционные условия, требующие проверки до первых оплат.

Для каждой работы используется прямой адрес `#work/<id>`. Пример: `#work/rescuer-03`. Hash-ссылки работают на GitHub Pages без настройки серверных маршрутов. Поисковые роботы и мессенджеры, не выполняющие JavaScript, видят общее описание и превью коллекции.

## Изображения

Готовые веб-копии включены в Git; для запуска сайта обработчик изображений не требуется. При замене исходников выполнить `node scripts/prepare-images.cjs` с доступным модулем `sharp`.

Скрипт создаёт копии шириной 800, 1280 и 2000 px в sRGB, удаляет метаданные экспорта и не перезаписывает оригиналы. Цвет и композиция самих работ не редактируются. Фотографии сохраняют исходные пропорции. Белые поля на листе и рамы создаются CSS; подписи сообщают, что это визуализация.

## Проверки

```sh
node --test tests/catalog.test.cjs
node scripts/serve.cjs
# В другом терминале, с установленным Playwright и Chromium:
node tests/browser.cjs
```

Браузерные проверки используют модуль `playwright` и установленный Chromium. Для установки вспомогательных зависимостей: `npm install`, затем `npx playwright install chromium`. Версии инструментов зафиксированы в `package.json`. Рабочая версия сайта не загружает эти зависимости.

Тестируется геометрия отпечатков, восемь вариантов заказа, 24 сочетания размера/оформления, URL и история браузера, увеличение фото, копирование с отказом в разрешении, ширины 360–1440 px, отсутствующие изображения, работа без JavaScript и отсутствие открытого бот-токена. Скриншоты сохраняются в игнорируемой папке `test-results/`.

Для проверки опубликованной версии можно задать `TEST_URL=https://yopech.github.io/etudes-urbaines-webpage/` перед запуском `tests/browser.cjs`. Скрипт не отправляет сообщения и не совершает заказы.

## Публикация

Репозиторий: https://github.com/yopech/etudes-urbaines-webpage

Сайт: https://yopech.github.io/etudes-urbaines-webpage/

Существующий сайт публикуется через GitHub Pages. После коммита и обычного push в `main` дождаться завершения публикации и проверить HTML, JS и изображения на публичном адресе. Не использовать force-push. `.DS_Store`, секреты и результаты локальных проверок не включаются в коммит.

## Заказы и оставшиеся операционные вопросы

Форма с открытым Telegram bot token удалена. Новый код ничего не отправляет через Bot API и не собирает имя/телефон. Покупатель копирует текст с параметрами и сам отправляет его в личный чат `@yopech`. При недоступном буфере текст выделяется для ручного копирования.

**Старый токен нужно отозвать через BotFather.** Удаление его из текущего кода не отзывает его и не удаляет из истории Git. История репозитория не переписывалась.

Принятые для сайта решения: 40×60 и 60×90 — размеры листа; полный кадр с белыми полями для 4:3; ориентировочные цены 5 900/9 900 ₽; упаковка включена, доставка отдельно. Для горизонтальных работ размеры отображаются как 60×40 и 90×60.

До приёма оплат проверить себестоимость малого размера, физические пробы печати, макеты, срок 5–7 рабочих дней, контактный упаковочный материал, полезные размеры тубуса, подпись и сертификат. Подготовить реквизиты продавца и условия оплаты, обмена и возврата. На сайте условия и итоговая сумма подтверждаются до оплаты; онлайн-оплаты нет.

Тираж, выбор редакции Artkoko и фотографии физических образцов не заявляются как подтверждённые факты до получения соответствующих данных. Все четыре работы остаются в каталоге независимо от этих необязательных материалов.
