# Аудит Études Urbaines — 15 октября 2026

Основание: пользовательский universal-ui-ux-prompt.md. Приоритет имеют согласованные требования выставки: ночной вход с рубильником, растровые вывеска/рамы/светильники, четыре работы, отсутствие декоративных микроподписей. Общие рекомендации для светлого приложения не заменяют эту концепцию.

Сценарии: вход → зал → фотография крупно → запрос автору; зал → запрос; закрытие/отмена → та же работа и позиция; прямая ссылка на работу/просмотр/запрос. Отправка сообщения в Telegram остаётся действием посетителя.

## Проверки

- `npm test`: шесть проверок каталога, размеров и текста заказа.
- `node tests/exhibition.cjs`: вход, постоянное мерцание, четыре работы, просмотр, выбор размера/комплектации, WCAG 2 A/AA через axe, выключение; ширины 320, 375, 390, 430, 768 и 1440 px.
- `node tests/exhibition-audit.cjs`: отдельные черновики выбора, ориентация листа и цены, фокус, история, прямые ссылки, увеличенная компоновка, ошибки входных изображений и просмотра, доступная галерея без JavaScript, axe открытого запроса.
- Снимки: `test-results/audit-order-390.png`, `test-results/audit-exhibit-390.png`, стандартные снимки выставки.

## Ограничения проверки

Проверка выполняется Chromium с эмуляцией размеров. Физические iOS/Android не подключены; WebKit runtime отсутствует. Это не сертификация WCAG и не измерение плавности на реальном телефоне. Telegram-сообщения и платежи во время тестов не отправляются. Сохранение выбора — в памяти текущего посещения, не между перезапусками браузера. Старые тесты прежнего каталожного интерфейса не объявляются пройденными; для выставки используются отдельные актуальные проверки.
